氣泡排序法 (Bubble Sort)

1. 基本原理與操作方式

原理：重複走訪要排序的數列，每次比較相鄰的兩個元素，若順序錯誤就將它們交換。走訪數列的工作會重複進行，直到沒有再需要交換的元素為止。

操作：每一輪比較會把當前未排序區段的最大值（或最小值）像氣泡一樣浮動到陣列的最後面。

2. 複雜度分析

  • 最佳時間複雜度：O(n)
  • 平均時間複雜度：O(n²)
  • 最差時間複雜度：O(n²)
  • 空間複雜度：O(1)

3. 程式實作 (數據模擬)

以下為 Python 實作核心程式碼：


def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
